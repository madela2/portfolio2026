Pawpartner - Dog Activity Tracker

Pawpartner is an activity-tracking system designed to improve dog wellbeing and strengthen the bond between dogs and their owners. The system uses a wearable Micro:Bit sensor to track activity and presents the data in a web-based interface with actionable insights for new dog owners.

  • Team: Team project with two interaction designer students and three web developer students
  • Course: Web of Things
  • My role: Frontend developer
  • Tech: Micro:Bit, Web Bluetooth, JavaScript, MongoDB, HTML, CSS
View GitHub repository

Project overview

Pawpartner is an activity-tracking system for dogs that combines hardware sensors and a web interface. A wearable Micro:Bit measures data, which is transmitted via Web Bluetooth to a web application. The data is stored in a database and visualized to help owners understand whether their dog is getting enough daily activity.

The project focused on making activity data easy to understand and actionable, especially for new dog owners who may struggle to know how much exercise their dog needs.

  • Collaborating closely with backend and harware contributors to integrate data flow
  • Participating in UI and usability decisions
  • Implementing the profile page and the relationship status page

How it works

  1. A Micro:Bit with a built-in accelerometer tracks the dog's movement.
  2. Activity data is sent to a web application via Web Bluetooth (BLE).
  3. The web application sends the data to a backend using REST APIs.
  4. Activity data is stored in a MongoDB database.
  5. The web interface requests stored data through APIs and displays activity summaries.
